# منصة عيادات الأطباء

واجهة ويب عربية/إنجليزية مبنية بـ React وVite، وتستخدم Firebase Authentication وCloud Firestore. هذا المستودع يحتوي الواجهة وقواعد Firestore؛ رفع الواجهة إلى Vercel **لا ينشر قواعد Firestore تلقائياً**.

## تشغيل محلي

- يتطلب Node.js `24.12` أو أحدث، حسب متطلبات بعض التبعيات الحالية.
- ثبّت الحزم باستخدام `npm ci` ثم شغّل `npm run dev`.
- تحقق من الأنواع والبناء باستخدام `npm run lint` و`npm run build`.
- انسخ `.env.example` إلى `.env.local` وأضف `VITE_GOOGLE_MAPS_API_KEY` عند الحاجة للخريطة. قيّد المفتاح بنطاقات الموقع وواجهات Google Maps المطلوبة؛ لا تستخدم مفتاحاً بصلاحيات غير محدودة.

## Firebase وVercel

- يستخدم التطبيق مشروع Firebase `prismatic-fire-083d0` وقاعدة Firestore المسماة `ai-studio-e4e5b186-cf8b-4dd6-b0ea-4d16b4ea8a97` كما هو محدد في `firebase-applet-config.json` و`firebase.json`.
- فعّل مزود Google في Firebase Authentication وأضف نطاقات الإنتاج والمعاينة المسموح بها قبل اختبار تسجيل الدخول.
- إعدادات Firebase الموجودة في تطبيق المتصفح ليست أسرار خادم. احمِ المشروع بقواعد Firestore، وقيود مفاتيح Google، وإعدادات Authentication الصحيحة.
- بعد مراجعة القواعد واختبارها على قاعدة Emulator، يمكن نشر قواعد Firestore من حساب مخوّل عبر `firebase deploy --only firestore:rules`. **هذا الأمر يستبدل القواعد المنشورة لقاعدة البيانات المحددة في إعداد Firebase؛ خذ نسخة احتياطية وراجع التغييرات قبل التنفيذ.**
- إعدادات Vercel للنشر لا تغني عن نشر القواعد، إعداد Google Maps، أو إعداد نطاقات OAuth.

## متطلبات قبل استخدام بيانات حقيقية

- لا توجد بيانات أطباء تجريبية معتمدة في مسار الإنتاج؛ يلزم إدخال كل مقدم خدمة والتحقق من ترخيصه يدوياً قبل اعتماده.
- اختبر الحجز والإلغاء والتزامن بين مستخدمين على Firestore Emulator، واختبر كل قواعد الوصول للملف الطبي والمحادثات وسجلات المرضى.
- أضف سياسة خصوصية وموافقة واضحة، وحدد الغرض من جمع البيانات، وصلاحيات الاطلاع، ومدد الاحتفاظ والحذف، والنسخ الاحتياطي والاستجابة للحوادث. اطلب مراجعة قانونية/تنظيمية قبل تشغيل بيانات صحية حقيقية.
- لا ترفع مستندات الترخيص أو سجلات المرضى إلى تخزين عام. أي مسار لرفع الملفات يحتاج إعداد تخزين خاصاً وقواعد وصول وفحوصاً مناسبة.
- راجع أداء التحميل على الهواتف والاتصالات البطيئة، وأضف اختبارات آلية قبل اعتماد إصدار إنتاجي.

## ملاحظة على قواعد الأمان

ملف `firestore.rules` هو مصدر القواعد للمراجعة والنشر. لا تعتبر وجوده في المستودع دليلاً على أنه منشور بالفعل؛ تحقّق من القواعد النشطة في مشروع Firebase قبل الإطلاق.
